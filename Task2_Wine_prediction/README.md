## Project Overview

This project focuses on predicting the quality of wine based on its chemical properties using Machine Learning classification algorithms.

The dataset contains several physicochemical features such as acidity, alcohol content, density, pH, sulphates, and more. Using these features, the model predicts whether the wine quality is good or bad.

---

# Objectives

- Analyze wine chemical properties
- Perform data preprocessing and visualization
- Train multiple machine learning classification models
- Compare model performance
- Predict wine quality accurately

---

# Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

---

# Machine Learning Models Used

1. Random Forest Classifier
2. Stochastic Gradient Descent (SGD) Classifier
3. Support Vector Classifier (SVC)

---

# Dataset Information

The dataset includes features such as:

- Fixed acidity
- Volatile acidity
- Citric acid
- Residual sugar
- Chlorides
- Free sulfur dioxide
- Total sulfur dioxide
- Density
- pH
- Sulphates
- Alcohol
- Quality

Target Variable:
- `quality`
